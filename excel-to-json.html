📋 Excel → JSON 转换工具

将小程序导出的Excel数据转换为JSON，导入到网页版猫咪症状日记

步骤说明
第1步：点击下方区域上传从小程序导出的Excel文件(.xls)
第2步：自动转换为JSON，预览数据
第3步：点击「直接导入到网页版」按钮，自动写入数据并跳转
1️⃣ 上传Excel文件
📄
点击选择Excel文件（.xls / .xlsx）
支持小程序导出的症状/用药/体重数据
2️⃣ 转换结果
✅ 直接导入到网页版（推荐） 📥 下载JSON文件

「直接导入」会自动写入数据并跳转到猫咪症状日记主页

ℹ️ 说明

· 本工具在浏览器本地运行，数据不会上传到任何服务器。

· 支持小程序导出的HTML格式xls和标准xlsx格式。

· 自动识别Sheet/表格类型（症状/用药/体重），不依赖Sheet名称。

· 导入后数据存在浏览器本地，与网页版共享同一存储。

· 如果网页版已有数据，导入会合并（不会覆盖已有记录）。
